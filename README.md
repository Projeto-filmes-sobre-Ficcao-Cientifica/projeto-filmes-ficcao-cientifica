# Top 10 Filmes de Ficção Científica

Este projeto consiste em um site desenvolvido com **HTML**, **CSS** e **JavaScript**, apresentando uma seleção de **10 filmes de ficção científica**. Cada página contém informações sobre um filme.

## Objetivo

O principal objetivo deste projeto é servir como uma **atividade prática para aprender e utilizar o Git Bash**, aplicando os principais comandos de versionamento com Git e publicando o projeto no GitHub.
